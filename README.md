# Website Profil SMK Muhammadiyah Pakem

Proyek website sekolah dibuat untuk memenuhi tugas LKPD Pemrograman Web - Kelas XI RPL.

## Struktur File

```
website-sekolah/
│
├── index.html        ← Halaman utama website
├── style.css         ← File styling (tampilan)
├── README.md         ← Dokumentasi proyek
└── images/
    ├── logo.png          ← Logo sekolah
    ├── sekolah.jpg       ← Foto gedung sekolah
    ├── kegiatan.jpg      ← Foto kegiatan siswa
    ├── lab.jpg           ← Foto laboratorium
    ├── upacara.jpg       ← Foto upacara
    ├── ekstrakurikuler.jpg ← Foto ekstrakurikuler
    └── wisuda.jpg        ← Foto wisuda
```

## Menu Navbar (6 menu)

1. **Beranda** - Halaman utama dengan hero section dan statistik sekolah
2. **Profil Sekolah** - Sejarah, visi, misi, dan data sekolah
3. **Program Keahlian** - 4 program keahlian yang tersedia
4. **Berita** - Berita dan informasi terkini sekolah
5. **Galeri** - Foto-foto kegiatan sekolah
6. **Kontak** - Informasi kontak dan form pesan

## Cara Menjalankan

1. Simpan semua file dalam satu folder.
2. Tambahkan foto ke folder `images/` sesuai nama file di atas.
3. Buka `index.html` menggunakan browser (Chrome / Edge).

## Fitur Website

- Navbar sticky dengan efek hover dan highlight aktif saat scroll
- Tombol hamburger untuk tampilan mobile
- Desain responsif (laptop dan smartphone)
- Animasi hover pada kartu program keahlian dan galeri
- Form kontak interaktif
- Footer lengkap 4 kolom
- Statistik sekolah (500+ siswa, 40+ guru, dll.)
- Kartu berita dengan tanggal
- Galeri 6 foto dengan efek caption hover

## Teknologi

- HTML5
- CSS3 (Flexbox, Grid, Media Query)
- JavaScript (toggle menu, scroll highlight)

## Upload ke GitHub Pages

1. Buat repository baru di github.com
2. Upload seluruh isi folder ini
3. Aktifkan GitHub Pages di Settings → Pages → Branch: main
4. Website akan online di: `https://username.github.io/nama-repo/`
